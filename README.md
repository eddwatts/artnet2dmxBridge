# artnet2dmxBridge
My Artnet to dual DMX bridge with web interface for setup, testing and monitring

This project is using a PICO W or PICO 2W and 2x MAX485 to create a bridge between Artnet and DMX devices.
A SSD1306 can be used for monitring.

Pins in use:<br>
2 - DMX universe A<br>
3 - DMX universe B<br>
4 - SDA on Screen<br>
5 - SCK on Screen<br>

This Project is untested as yet
